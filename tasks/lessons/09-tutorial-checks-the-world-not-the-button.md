# 튜토리얼은 "읽었는가"가 아니라 "세계가 그렇게 됐는가"로 판정해야 한다

"다음" 버튼으로 넘기는 튜토리얼은 아무것도 가르치지 않는다 — 눌러서 넘어가면 손은 배운 게
없다. 그래서 9단계 전부를 `check()` 함수 하나로 만들고, 그 함수는 **세계 상태만** 본다.

```js
{ id:'miner', check(){ return anyEntity(e => e.type==='miner' && e.net>=0 && !e.depleted) } }
{ id:'wire',  check(){ return anyEntity(e => e.logicForced && e.fEnable) }   // 제어기가 실제로 지배 중
```

## 버퍼를 보면 순간을 놓친다

3단계("용광로로 철판을 만든다")를 처음엔 `용광로.out['iron-plate'] > 0` 으로 봤다. 그런데
인서터가 0.83개/s 로 빼 가므로 4Hz 로 확인하는 튜토리얼이 그 순간을 놓치면 영원히 다음
단계로 못 간다. **상태가 아니라 사건을 세야 한다** — `prodStats.smelted` 누적 카운터를
`stepCrafter` 에 넣고 그걸 본다.

일반화: 판정 대상이 **소비되는 값**이면 누적 카운터를 따로 둬라. 재고는 사건의 증거가 아니다.

## 게이트에 음성 대조군이 필요하다

튜토리얼 게이트에서 제일 중요한 검사는 "단계가 올라갔다"가 아니라
**"아무것도 안 했을 때 안 올라간다"** 이다.

```
tutorial.doesNotAdvanceIdle : 20초 동안 아무것도 안 했을 때 단계 0 (0이어야)
```

이게 없으면 "저절로 진행되는 튜토리얼"도 전부 통과한다. 돌연변이(`if (!ok) return` →
`if (false) return`)로 이 게이트가 실제로 뒤집히는지도 확인했다.

## 상태로 못 보는 사건은 플래그로

"편집기를 열었다"는 세계 상태에 흔적이 없다. 그런 것만 `tutorial.flags` 에 두고,
그 외에는 전부 세계를 읽는다. 플래그가 늘어나면 그건 판정을 포기하고 있다는 신호다.
현재 플래그는 하나뿐이다.

## 진행은 저장에 실어라

튜토리얼 진행이 저장/복원에 안 실리면 불러오기 한 번에 1단계로 돌아간다.
`tut: {on, step, done, flags}` 와 `prod` 를 저장본에 넣고 게이트로 못박았다
(`tutorial.survivesSaveLoad`).
