# 모델 API 게이트는 "클릭이 먹히는가"를 하나도 보증하지 않는다

`__GAME.place()` 를 직접 부르는 게이트 43건이 전부 GREEN 이어도, 팔레트 클릭 핸들러가
안 붙어 있거나 화면 좌표 → 타일 역변환이 틀렸으면 게임은 손도 못 댄다. 그 경로는
모델 게이트가 지나가지 않는다.

그래서 별도 드라이버(`uismoke.js`)로 **합성 마우스 이벤트를 진짜 DOM 핸들러에 쏜다.**
팔레트 클릭 → 캔버스 좌클릭 드래그로 벨트 이어 깔기 → 커서 타일 역변환 확인 → R 회전 →
ESC → 우클릭 철거와 환급 → 인스펙터 → 제어기 클릭으로 편집기 열기 → 노드 추가 →
잠긴 노드 거부 → 예제 배선이 SVG 에 실제로 그려지는지 → 휠 확대 → 연구 시작.

하네스는 드라이버를 인자로 갈아끼우게 만들어 두면 채널(판정 JSON)을 공유할 수 있다:

```
python tests/harness.py              # 모델
python tests/harness.py uismoke.js   # 클릭 경로
```

**음성 대조군은 여기서도 필요하다.** "잠긴 노드는 눌러도 안 생긴다"를 검사할 때
*실제로 잠겨 있었음*(`locked` 클래스)을 함께 단언해야 한다. 안 그러면 이미 해금된 노드를
누르고 "안 늘었다"를 확인하는 무의미한 검사가 된다.
