## 2026-08-09 — 검증 결과를 기다리지 않고 커밋해, 구문이 깨진 테스트 드라이버가 커밋에 들어갔다
- 시도: 문장 편집기 작업을 마치고 회귀를 백그라운드로 돌린 뒤, 결과가 나오기 전에 커밋했다
- 실패 이유: 직전에 게이트를 다시 쓰면서 파이썬 문자열에 진짜 줄바꿈이 섞여 tests/driver.js 가 파싱 불가 상태였다. 하네스는 '게임이 부팅조차 못 했다'만 말하고 원인을 안 알려줘서, 게임 소스를 먼저 의심하느라 시간을 썼다
- 대안·다음엔: 커밋은 회귀 결과를 **읽은 뒤**에만 한다. 그리고 하네스가 결과를 못 찾을 때는 게임 소스뿐 아니라 **주입한 드라이버 자체의 구문**을 먼저 검사한다 — node -e 'new Function(fs.readFileSync(f))' 한 줄이면 즉시 갈린다
- 재사용 자산: 드라이버 구문 검사 한 줄 — node -e \"new Function(require('fs').readFileSync('tests/driver.js','utf8'))\"
